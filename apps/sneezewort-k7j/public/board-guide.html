Reading the Sneezewort board

The board shows everything on the shared list at a glance, newest entries first, so you can tell what is still open in a few seconds.

  • Open items appear as plain text.
  • Done items start with a tick.
  • Empty lists say so instead of showing a blank page.

The board reloads its entries each time you open the page.

Everyone who opens the board sees the same entries, because each page load reads the shared list directly instead of keeping its own copy.

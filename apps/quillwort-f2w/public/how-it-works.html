How Quillwort works

Quillwort keeps one shared list in a single place, so everyone who opens the front door sees the same five most recent items.

  1. 1. Someone adds an item to the shared list.
  2. 2. Quillwort reads the five newest entries each time the page loads.
  3. 3. Finished items are marked with a tick so they are easy to skip.

Lists refresh whenever you reload the page; nothing needs to be installed.

Every list on Quillwort is read straight from the shared source, which means the page you see is always the page everyone else sees.
